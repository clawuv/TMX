TMX v1.0.1

- 使用新的应用标识 `io.github.clawuv.tmx`，更新源为 `clawuv/TMX`。
- 修复更新包下载完成后，安装阶段错误未显示的问题。
- 捕获下载及安装通信异常，增加 macOS 临时转移运行提示。

### 升级说明

v1.0.0 使用旧标识 `io.github.he2dou.tmx`，无法跨标识应用内升级。请完全退出 TMX，下载对应平台安装包后手动替换安装。保留原有用户数据，不要使用清理工具卸载。

macOS Apple Silicon（arm64）：DMG 安装包或 ZIP；Windows x64：EXE；Linux x64：AppImage。

此版本未配置 Developer ID 签名或 macOS 公证；系统可能显示安全提示，macOS 自动安装仍可能受到签名校验限制。
