TMX v1.0.2

- 新增浅色主题品牌 Logo，保留深色主题标识。
- 增加主机监控采样，支持 POSIX 和 Windows 主机。
- 按操作系统分类快捷脚本，并在首次启动时初始化脚本。
- 优化终端会话、侧栏默认状态、启动画面和更新状态恢复。
- macOS 发布流程加入 Developer ID 签名、Apple 公证及签名和公证票据验证。

### 安装与升级

macOS 安装包适用于 Apple Silicon（arm64）；Windows 和 Linux 为 x64。

应用标识保持 `io.github.clawuv.tmx`。早期未签名、临时签名或使用旧应用标识的安装版可能无法应用内升级，请退出 TMX 后使用本版本安装包手动替换一次，保留用户数据。
