TMX v1.0.6

- 主题重绘为中性灰配色：深色模式界面 #282A2A、内容区 #181818；浅色模式界面 #F5F5F5，配套调整激活、输入、边框与文字层级。
- 左侧菜单与顶部标签的选中、悬停态改为纯背景填充并移除边框；设置弹窗配色与主窗口统一。
- 主机列表改为 Xshell 风格：单行名称布局、显示器图标、悬停背景高亮，All 视图下置顶主机平铺展示。
- 抽屉分割线支持双击收起；头部与内容区间距收紧，右侧按钮纵向对齐。
- SFTP 抽屉布局优化：过滤搜索框缩窄、刷新按钮移至搜索框左侧、连接信息移入路径行。
- 主窗口默认与最小宽度调整为 920px；菜单图标缩小至 15px、间距调整为 12px。

macOS Apple Silicon 安装包使用 Developer ID 签名并经 Apple 公证；Windows 和 Linux 安装包为 x64。
